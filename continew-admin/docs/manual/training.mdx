title: 实训工作台
description: 管理当前账号的私人资料，核对资料所有权和版本。

登录后打开「实训工作台 → 我的资料」。可上传单份不超过 5 MB 的 PDF、DOCX 或 TXT，预览、下载、替换或删除自己的资料。TXT 预览按 UTF-8 解码。

工作台用当前登录身份确定资料归属。相同租户下的另一名学生，即使知道文档编号，也无法查看、替换或删除这份文件。系统管理中的文件库与私人资料分开存储。

## 两人验收

### 人脸登录

在「个人中心 → 安全设置 → 绑定人脸」输入当前账号密码，勾选采集同意并开启摄像头。画面合格后点击「确定」。如希望刷脸自动识别账号，再点击「开启免输账号登录」并确认密码。已有绑定可直接开启。退出后选择「人脸登录 → 免输账号」，开启摄像头并点击「刷脸登录」。系统只比较当前租户已授权的模板，无法明确区分候选人时拒绝登录。本人可随时关闭免输账号模式，继续使用「指定账号」刷脸登录，或解绑以停用两种方式。

浏览器使用 localhost 或 HTTPS 访问时可以申请摄像头权限。两名学生分别绑定后可验证本人登录、他人验证失败、重录和解绑。验收时应单独说明照片重放风险；此版本仅实现单帧人脸比对。

### 私人资料

1. 学生甲上传一份记录，列表显示 v1。预览并下载，核对文字与原文件相同。
2. 学生乙登录，列表中应没有甲的记录。用乙的会话访问甲的内容接口，应收到「资料不可访问或版本已更新」。
3. 甲替换记录，资料编号保持一致，列表显示 v2。用 v1 的引用读取、替换或删除都应失败。
4. 甲删除记录，列表和原有 v2 引用均无法再取得正文。

## 小组对接

资料列表接口为 `GET /training/documents`。每条记录含 `documentId`、`version`、`fileName`、`fileSize` 和 `updatedAt`。文档编号是字符串，版本从 1 开始。

读取正文使用 `GET /training/documents/{documentId}/content?version=1` 并携带当前账号的登录凭据。预览与下载使用同一接口，文件内容没有公开静态链接。

后续分段时，在文档编号和版本号之外再加入 `chunkId`，并记录页码或段落号。问答引用和图关系证据采用这一组合。解析、向量索引和图谱属于后续模块。

## 图谱问答

资料列表展示图谱建立状态，点击图谱可以查看节点和关系原文。问答窗口可切换 RAG 与 GraphRAG；单文件入口限定当前文件，资料库入口限定当前用户的就绪文件。文件替换后自动重建新版本图谱，删除后由持久化清理队列清除 Neo4j 中的对应节点。图谱问答返回前复核资料版本。
