# 私人资料问答使用说明

登录[本地工作台](http://localhost:5173/)后，进入“我的资料”。启动步骤见仓库首页。

1. 在「我的资料」选择「RAG」或「同时构建」，点「上传资料」，按住 `Ctrl` 或 `Shift` 同时选择[校准箱交接单.docx](./校准箱交接单.docx)和[校准箱归还指引.pdf](./校准箱归还指引.pdf)。等两行的「问答索引」显示「可问答」。
2. 在工作台右侧「AI 智能问答」选择「RAG」，输入“星桥校准箱在哪里领取，归还截止时间是什么？”。
3. 回答应包含“青岚楼 308 室”和“周五 16:40”。展开「原文依据」，核对《校准箱交接单》的领取地点和《校准箱归还指引》第 2 页的截止时间。
4. 点文件行的「问答」可单独查询该文件。也可以上传[器材借用指南 TXT](./工程实训器材借用指南.txt)，问“LAB-07 放在哪里？”或“一台 LAB-07 的采购价格是多少元？”。资料里只写了存放位置。
5. 在「资料库检索」输入设备编号、关键词或文件名，核对命中段落。点「替换」更新文件后检查版本号，待新索引就绪再提问。勾选这次上传的演示文件，点「批量删除」，核对份数后确认，检查列表和检索结果。

上传和替换会自动建立新版本索引。替换或删除后，旧版立即退出查询范围。后台清理旧版向量索引和图谱，文件被占用或服务暂不可用时保留待办供后续重试。索引失败时，将鼠标放在「失败」上查看原因，可点「重试」或替换为可读取的文件。

单文件上传上限为 5 MB，可索引正文最多 12 万字、1200 个片段，PDF 最多 300 页。PDF 需有文本层，扫描件先做 OCR。Word 支持 DOCX 正文段落和表格文字。每次提问独立检索。

## 双账号隔离

用 Chrome 登录学生 A，用 Edge 登录学生 B，两个浏览器均访问 `http://localhost:5173/`。核对右上角账号。在 A 上传带独有编号的演示文档，在 B 的「资料库检索」查询同一编号，确认 B 的列表和检索结果均不包含 A 的文件。

## 问答结果核对

在单份资料问答里展开「查看本次问答流程」，查看本次检索的资料份数、候选片段数和返回的引用数。分别验证以下场景。

| 提问 | 工作流行为 |
| --- | --- |
| 普通借用最迟几点归还？ | 上传借用指南后，工作台回答应显示 17:30 和原文依据。 |
| 125 加 375 等于多少？ | 在工作台提问，回答 500，标注「通用回答 · 无资料引用」。 |
| 一台 LAB-07 便携示波器的采购价格是多少元？ | 检索命中设备段落，原文不足以回答价格，提示补充资料。 |

另附 [Dify 工作流模板](./Dify问答分支演示.yml)。在 Dify 工作室从 DSL 文件创建应用，选择该文件后点「测试运行」。可用单份资料问答的候选片段数和核验引用数复现分支。例如输入 3 和 1 查看有依据分支，3 和 0 查看补资料分支，0 和 0 查看调整检索词分支。模板只接收计数，实际检索和回答由 Windows 工作台本地执行。

- 文件服务在数据库保存租户、所有者和版本。上传或替换时，同一次数据库写入把该版本标记为待处理。后台从队列取文件，成功后只把仍为当前版本的那一行标记为就绪。[文件服务](../continew-admin/continew-system/src/main/java/top/continew/admin/training/service/TrainingDocumentService.java) · [后台索引队列](../continew-admin/continew-system/src/main/java/top/continew/admin/training/service/TrainingIndexService.java)
- 本地程序提取文本和页码，分段后由 `nomic-embed-text` 生成 768 维向量，将原文片段、位置与向量写入该版本独立的 SQLite 索引。`qwen2.5:3b` 根据候选段落生成回答。[提取、检索和生成代码](../continew-admin/training-rag/worker.py)
- 管理员删除账号时，数据库同时删除该账号的实训资料并记录清理任务。后台按文档编号和版本清理向量索引与图谱，按租户和账号清理活体登录模板。[隐私清理服务](../continew-admin/continew-system/src/main/java/top/continew/admin/training/service/TrainingPrivacyCleanupService.java)
- 提问时，后端从登录态取得用户和租户，列出允许检索的就绪版本。程序将问题转成向量，按距离从这些文件挑选候选段落，调用本地生成模型，再核验引用。后端返回前复查来源权限与版本。[问答服务](../continew-admin/continew-system/src/main/java/top/continew/admin/training/service/TrainingQuestionService.java) · [前端问答窗口](../continew-admin-ui/src/views/dashboard/workplace/components/DocumentQuestion.vue)

模型保存在 `D:\Engineering\local-runtime\ollama-models`，问答索引保存在 `D:\Engineering\local-runtime\rag\index`。重建工程的 Python 环境时，可用启动脚本指定的解释器安装 [requirements.txt](../continew-admin/training-rag/requirements.txt)。
